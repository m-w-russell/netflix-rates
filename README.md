# nf-rate
This is a Chrome extension which shows IMDb ratings on Netflix details pages. These are fetched from the OMDb API via my proxy.  
You can find the proxy source [here](https://github.com/m-w-russell/netflix-rates-proxy).
You can install the extension [here](https://chromewebstore.google.com/detail/show-ratings-on-netflix/ngadlchdebgbhfcclfecgkjgdngfmenp).
